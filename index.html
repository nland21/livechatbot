    등록된 키워드 규칙

      스킬 관리

      AI 자동 답변이 참고할 주제별 지식입니다. 트리거 키워드를 비워두면 항상 포함되는 기본 스킬이 됩니다.

      🔑 Claude API 연동

      API 키는 서버(Supabase Vault)에 암호화되어 저장되고, 실제 호출은 서버의 Edge Function이 대신 수행합니다. 로컬PC(확장 프로그램)에는 API 키가 전혀 저장되지 않고, 이 페이지에서도 저장 후에는 값을 다시 볼 수 없습니다 (쓰기 전용).

      직전 AI 호출로부터 이 시간이 지나야 다음 질문에 다시 AI를 부릅니다. 짧을수록 빠르게 답하지만 비용이 늘어납니다.

      한 방송에서 AI를 이 횟수만큼 부르면, 이후 질문은 답하지 않습니다 (비용 폭주 방지 안전장치).

      같은 시청자가 이 시간 안에 표현만 바꿔서 또 물어봐도 AI를 다시 부르지 않습니다.

      🤖 AI 답변 기본 설정 (모든 답변에 항상 적용)

      여기 적은 내용은 스킬 매칭 여부와 상관없이 모든 AI 답변에 항상 먼저 적용됩니다. 이 챗봇의 정체성/판단 기준은 여기에, 특정 주제의 세부 내용은 아래 개별 스킬에 나눠서 적어주세요.

      + 새 스킬 추가

      📁 파일로 여러 개 한 번에 등록

      JSON, CSV, 엑셀(.xlsx) 파일을 올리면 내용을 미리 보여드리고, 확인 후 한 번에 등록합니다.

      CSV/엑셀 열 이름: 스킬제목, 적용범위(공통 또는 방송전용), 라이브아이디(방송전용일 때만), 트리거키워드(쉼표로 구분, 비우면 항상 포함), 매칭방식(하나라도포함 또는 모두포함), 스킬내용, 사용여부(사용 또는 미사용, 생략시 사용)
      JSON 형식: 예시 파일을 받아서 형식을 확인해주세요.

      등록된 스킬 0개 선택

      각 스킬의 ▲▼ 버튼으로 같은 그룹(공통 / 특정 라이브 전용) 안에서의 우선순위를 바꿀 수 있습니다. 숫자가 작을수록(우선순위 1에 가까울수록) AI에게 먼저 전달됩니다.

      선택한 항목이 있으면 선택한 것만, 없으면 전체를 내보냅니다.

      제품 스펙 관리

      모델별 스펙을 저장해두면, AI 자동답변이 질문에 언급된 모델명을 알아보고 정확한 스펙으로 답변합니다. (스펙 질문은 여기 저장된 값만 사용하고, 없는 항목은 추측하지 않도록 안내됩니다)

        🗺️ 전체 구조 한눈에 보기

        이 시스템은 서로 다른 3곳에서 동작하는 3개 패키지로 이루어져 있고, 데이터는 항상 Supabase(서버)를 중심으로 흐릅니다.

        • server-sync (Supabase) — 모든 데이터(예약문구·키워드·스킬·제품스펙·계정·PC상태·다운로드 파일)가 저장되는 중앙 서버. schema.sql 한 번 실행으로 전체 구조가 만들어집니다.
        • admin-webpage (관리자 웹페이지) — 브라우저로 접속해서 위 데이터를 등록·수정하는 화면. 정적 파일이라 아무 웹 호스팅에나 올리면 됩니다(추천: GitHub Pages, 무료).
        • live-chat-bot (로컬PC 확장 프로그램) — 실제로 라이브 방송 중인 PC의 크롬에 설치. 서버 데이터를 1분마다 받아와서, 채팅을 감시하고 자동으로 답변을 올립니다.

        흐름: 관리자 웹페이지에서 저장 → Supabase에 저장 → 로컬PC가 1분마다 동기화 → 실제 라이브 채팅에 자동 반영. 그래서 설치 순서도 항상 서버 → 웹페이지 → 로컬PC 순서를 권장합니다.

        1단계 · 서버(server-sync / Supabase) 설치

        새 Supabase 프로젝트 만들기

        1. supabase.com에서 새 프로젝트를 생성합니다.
        2. 좌측 메뉴 SQL Editor로 들어가서, 이 탭 위쪽에서 내려받은 server-sync의 schema.sql 내용을 전부 붙여넣고 실행합니다.
        3. Authentication > Sign In / Providers에서 "Confirm email(이메일 확인)" 옵션을 꺼둡니다. (안 꺼두면 새 계정을 만들어도 이메일 인증을 눌러야만 로그인이 됩니다)

        마스터관리자 계정 만들기

        1. Authentication > Users > Add user > Create new user에서 계정을 직접 만듭니다. ("Auto Confirm User" 옵션이 있으면 켜주세요)
        2. schema.sql 맨 아래 "마스터관리자 최초 1회 부트스트랩" 부분의 이메일을, 방금 만든 계정 이메일로 바꿔서 그 구문만 다시 한 번 SQL Editor에서 실행합니다. (이후 계정은 마스터관리자가 로그인해서 "계정 관리" 탭에서 직접 만들 수 있습니다)

        Claude API 키 연동 (Edge Function)

        1. Supabase CLI로 이 프로젝트를 supabase link한 뒤, ask-claude Edge Function을 배포합니다 (supabase functions deploy ask-claude).
        2. 웹페이지에 로그인 후 "스킬 관리" 탭 > Claude API 연동에서 API 키를 등록합니다. (Vault에 암호화 저장되며, 브라우저에는 절대 남지 않습니다)
        ⚠️ Storage 버킷(releases)이 이미 있는 프로젝트에 다시 실행하는 경우: schema.sql은 on conflict do nothing으로 안전하게 재실행되도록 만들어져 있어서, 이미 실행한 적 있는 프로젝트에 다시 실행해도 데이터가 지워지지 않습니다.
        2단계 · 관리자 웹페이지(admin-webpage) 설치
        1. 이 탭에서 admin-webpage 최신 zip을 내려받아 압축을 풉니다.
        2. config.js 파일을 열어 방금 만든 Supabase 프로젝트의 url과 anonKey(Project Settings > API에서 확인)로 값을 바꿔줍니다.
        3. 전체 폴더를 정적 호스팅에 올립니다. 가장 간단한 방법은 GitHub 저장소를 하나 만들어 이 폴더를 올리고, 저장소 설정 > Pages에서 배포하는 것입니다.
        4. 배포된 주소로 접속해서 1단계에서 만든 마스터관리자 계정으로 로그인합니다.

        이후로는 새 계정 만들기(관리자/웹관리자/로컬매니저), 예약문구·키워드·스킬·제품스펙 등록, 다음 라이브 예약, 로컬PC 상태 확인을 전부 이 화면에서 합니다.

        3단계 · 로컬PC 확장 프로그램(live-chat-bot) 설치

        설치

        1. 이 탭에서 live-chat-bot 최신 zip을 내려받아, 라이브 방송에 쓸 PC에서 압축을 풉니다.
        2. 크롬 주소창에 chrome://extensions 입력 > 우측 상단 "개발자 모드" 켜기 > "압축해제된 확장 프로그램을 로드합니다" > 압축 푼 폴더 선택.

        서버 연동 로그인

        1. 확장 프로그램 아이콘 > 옵션(⚙️) 페이지를 엽니다.
        2. "서버 연동" 탭에서 Supabase 주소/anon key, 그리고 로컬매니저(또는 관리자) 계정으로 로그인합니다. (웹관리자 계정은 로컬PC 로그인이 안 됩니다)
        3. 로그인 직후 1회 동기화가 자동 실행되어, 서버에 등록된 예약문구·키워드·스킬 등을 받아옵니다.

        화면 요소 지정 (PC마다 최초 1회)

        1. 네이버 쇼핑라이브 관리툴 상황판(tool.shoppinglive.naver.com/broadcasts/.../dashboard) 페이지를 엽니다.
        2. 옵션 페이지 "연결 설정" 탭에서 채팅 입력창 / 전송 버튼 / 채팅 목록 / 라이브 진행시간 표시 / 시청자 메시지 마커(☆) / 닉네임 영역을 순서대로 클릭해서 지정합니다.
        3. "테스트 전송"으로 실제 채팅창에 메시지가 올라가는지 확인합니다.

        시작

        1. 필요한 기능(예약문구/키워드/AI 자동답변)을 켜고 ▶ 시작을 누릅니다. 이후로는 관리자 웹페이지의 "로컬PC 상태" 탭에서 원격으로 시작/정지/로그아웃도 가능합니다.

        • 🖥️ 로컬PC 상태 — 지금 연동된 모든 PC의 접속 상태, 기능 켜짐/꺼짐, 자동채팅 실행 여부를 실시간으로 확인하고, 원격 시작/정지/로그아웃까지 가능.
        • 📦 다운로드(지금 이 탭) — 3개 패키지 최신 버전 보관 및 이 매뉴얼. 마스터관리자 전용.
        • 👤 계정 관리(마스터관리자 전용) — 관리자/웹관리자/로컬매니저 계정 생성·역할변경·강제로그아웃.
        🏢 다른 PC 추가 / 신규 회사 도입 체크리스트

        기존 회사에 방송 PC만 추가하는 경우

        1. 3단계(로컬PC 확장 프로그램 설치)만 새 PC에서 그대로 반복합니다. 서버·웹페이지는 이미 있으니 새로 만들 필요 없습니다.
        2. 새 PC용 로컬매니저 계정이 필요하면, 마스터관리자가 "계정 관리" 탭에서 하나 더 만들어줍니다.

        완전히 새로운 회사가 이 시스템 전체를 도입하는 경우

        1. 1 → 2 → 3단계를 처음부터 그대로 진행합니다 (새 Supabase 프로젝트 + 새 웹페이지 배포 + 새 확장 프로그램 설치).
        2. 제품/브랜드가 다르면 "스킬 관리"와 "제품 스펙"에 등록하는 내용만 새 회사 것으로 채우면 됩니다 — 코드 자체는 특정 브랜드에 종속돼 있지 않습니다.
        3. 회사마다 완전히 독립된 Supabase 프로젝트를 쓰는 구조라서, 데이터가 서로 섞이지 않습니다.
        🔧 문제가 생겼을 때 (트러블슈팅 요약)

        크롬 F12 콘솔에 진단 로그가 이미 심어져 있습니다. 순서대로 확인하면 어느 단계에서 막혔는지 바로 특정됩니다.

        • 👀 채팅 목록 감시 시작이 안 보임 → 옵션 페이지에서 "채팅 목록" 요소를 다시 지정
        • 💬 시청자 메시지 확인이 안 보임 → ☆ 마커 선택자가 화면 구조 변경으로 깨졌을 가능성 (재지정 필요)
        • 🔑 키워드 매칭이 안 뜨는데 채팅은 인식됨 → 등록된 키워드/매칭방식(AND·OR)을 다시 확인
        • 🤖 AI에게 질문 전달이 안 뜸 → 옵션 페이지에서 "AI 자동 답변" 토글, 그리고 웹페이지의 API 키 상태(✅ 설정됨) 확인
        • 🔴 로그인 세션이 끊긴 것으로 보입니다 → 관리툴 탭에서 네이버 재로그인 필요 (자동 재로그인은 보안상 지원하지 않습니다)

        계정 관리

        마스터관리자만 볼 수 있는 화면입니다. 새 계정을 만들거나, 역할을 바꾸거나, 계정을 비활성화할 수 있습니다.

        역할 안내
        · 관리자 — 계정 관리만 제외, 웹 콘텐츠 편집 + 로컬 PC(확장 프로그램) 로그인 모두 가능
        · 웹관리자 — 웹 콘텐츠 편집만 가능 (로컬 PC 로그인 불가)
        · 로컬매니저 — 로컬 PC(확장 프로그램) 동기화 로그인만 가능 (웹 콘텐츠 편집 불가)
